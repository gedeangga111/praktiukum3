## Deskripsi Proyek
Proyek ini merupakan website katalog produk dan nota pesanan yang dibuat menggunakan PHP, HTML, dan Tailwind CSS.

Website ini memiliki dua halaman utama:
1. Katalog produk untuk menampilkan daftar barang.
2. Nota pesanan untuk memasukkan nama pembeli, memilih produk, menentukan jumlah barang, dan menghitung total pembayaran.

## Fitur
- Menampilkan katalog produk.
- Form pemesanan produk.
- Validasi nama pembeli.
- Validasi jumlah barang berdasarkan stok.
- Perhitungan subtotal belanja.
- Perhitungan diskon belanja.
- Perhitungan total pembayaran.

## Daftar Produk
1. Keyboard Gaming
2. Mouse Gaming
3. Headset Gaming
4. Flashdisk
5. SSD
6. RAM

## Tantangan yang Dikerjakan
- Membuat form pemesanan menggunakan PHP.
- Menghitung subtotal dan diskon belanja.
- Menampilkan ringkasan pesanan.
- Memvalidasi jumlah pesanan sesuai stok produk.

## Cara Menjalankan
1. Simpan folder proyek di direktori htdocs XAMPP.
2. Jalankan Apache melalui XAMPP.
3. Buka browser.
4. Akses http://localhost/praktikum3/
